Carlowe Properties LLC

Meridian Acquisition Funnel

Overview

Meridian is a web-based business system designed to streamline internal operations and improve how information is organized, accessed, and acted on. The focus of this build was clarity, speed, and reducing friction in everyday workflows.

Problem

Most small business workflows rely on scattered tools, inconsistent tracking, and manual processes. This creates:

  • Lost or duplicated information
  • Slow decision-making
  • No centralized operational view
Solution

Meridian was built as a clean, dashboard-style interface focused on operational efficiency — usability over complexity so users can understand and act quickly.

  • Centralized dashboard for key business data
  • Structured layout for fast information scanning
  • Modular UI components for scalability
  • Simplified navigation to reduce cognitive load
Key Features
Unified dashboard view Simplified navigation Modular layout Fast, lightweight interface
Outcome

Meridian demonstrates how structured UI design can replace fragmented workflows with a single operational hub. The system is designed to scale with additional features as business needs grow.

Tech Focus
Frontend UI architecture Component-based layout design Responsive interface structure

Carlowe Insurance LLC

Zenfield Insurance Dashboard

Overview

Zenfield is a modern digital interface concept focused on simplicity, clarity, and distraction-free user experience. It explores how minimal design can still support powerful functionality without overwhelming the user.

Problem

Many modern interfaces suffer from:

  • Overloaded dashboards
  • Too many competing visual elements
  • Poor focus on primary actions

The goal was to create a calm, structured digital environment with intentional design.

Solution

Zenfield was designed around a minimal UI philosophy where every element has a purpose.

  • Reduced visual noise
  • Strong spacing and hierarchy
  • Clear focus on primary actions
  • Lightweight layout system
Key Features
Minimal UI system Focus-first layout Clean grid structure Lightweight interface
Outcome

Zenfield serves as a design exploration into calm interfaces — showing how simplicity can improve usability, focus, and perceived quality. It functions as both a portfolio piece and a design direction prototype.

Tech Focus
UI/UX layout design Visual hierarchy systems Minimal interface architecture
